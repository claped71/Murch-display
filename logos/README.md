# Subcontractor logos

Drop a PNG (transparent background works best) named after the sub. The display
picks it up automatically on the next load — no code change needed.

| Sub | File to add |
|---|---|
| United Services | `united.png` |
| Brumont | `brumont.png` |
| ECCS | `eccs.png` |
| AB Power | `ab-power.png` |
| ITS | `its.png` |
| Workforce | `workforce.png` |
| Dig It | `dig-it.png` |
| Topland | `topland.png` |
| Hi Tech | `hi-tech.png` |
| SSI | `ssi.png` |
| GreenSol | `greensol.png` (already here) |

If a file is missing the card falls back to a coloured monogram, so a missing
logo never breaks the slide.
